# Select to Read — Google TTS

Edge/Chrome extension สำหรับอ่านข้อความที่เลือกบนหน้าเว็บด้วยเสียง Google ไม่ต้องรัน Python และไม่ต้องมี API key

## ติดตั้ง

1. เปิด `edge://extensions` หรือ `chrome://extensions`
2. เปิด **Developer mode**
3. กด **Load unpacked** แล้วเลือกโฟลเดอร์นี้ หรือกด **Reload** หากติดตั้งไว้แล้ว
4. รีเฟรชหน้าเว็บ แล้วเลือกข้อความ — ปล่อยเมาส์แล้วจะเริ่มอ่าน

ถ้าเลือกข้อความแล้วยังไม่อ่าน ให้รีเฟรชหน้านั้นแล้วเลือกใหม่อีกครั้ง โดยเฉพาะหลังกด Reload extension หน้าเว็บที่เปิดค้างอยู่จะยังใช้สคริปต์เก่า ต้องรีเฟรชก่อนจึงจะอ่านได้

ปุ่ม **■ Stop** อยู่ข้างข้อความที่เลือก ไอคอน extension ใช้เลือกภาษาและความเร็ว

## ลำดับการทำงาน

```
ข้อความที่เลือก → normalizeForSpeech() → แบ่งเป็นช่วงตามคำ → Google Translate TTS → เล่นต่อเนื่อง
```

ข้อความถูกแบ่งเป็นช่วงไม่เกิน 180 ตัวอักษร ตามขอบคำของ `Intl.Segmenter` ภาษาไทยจึงไม่ถูกตัดกลางคำ. ช่วงถัดไปถูกโหลดล่วงหน้าระหว่างเล่นช่วงปัจจุบัน

## ข้อควรรู้

ใช้ endpoint เสียงของ Google Translate ซึ่งไม่ใช่ API ทางการ ต้องต่ออินเทอร์เน็ต และ Google อาจจำกัดหรือเปลี่ยนได้. ถ้าต้องการบริการที่มี SLA ให้เปลี่ยนไปใช้ Google Cloud Text-to-Speech ที่มีคีย์
